# Student_Data_Management_Project--Python
🎓 Student Data Management System using Python 🐍
Built a simple console-based application to manage student records. The program allows users to:
 ✅ Add Students
 ✏️ Update Marks
 🗑️ Delete Records
 📄 View All Entries
 🚪 Exit Cleanly
This mini-project demonstrates core Python concepts such as dictionaries, functions, and user input handling. Great for beginners to practice CRUD operations!
