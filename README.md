🎓 Student Data Management System

A simple and interactive console-based Python application to manage student records.

📌 Overview

This project is a Python-based Student Data Management System that performs essential CRUD operations.
It helps users easily manage student details through a clean, menu-driven console interface.

🚀 Features
✅ Add Students

Add new student details such as name and marks.

✏️ Update Marks

Modify existing student records quickly and easily.

🗑️ Delete Records

Remove any student entry from the database.

📄 View All Entries

Display all stored student records in a neat, readable format.

🚪 Exit Cleanly

Terminate the program safely with a smooth exit message.

🛠️ Tech Used

Python 3

Dictionaries for data storage

Functions for modular code

Loops & Conditionals for menu logic

User Input Handling

📚 What This Project Demonstrates

This mini-project showcases:

Basic to intermediate Python concepts

Understanding of CRUD operations

How to design a menu-based console application

Use of data structures for record management

Perfect for beginners who want hands-on practice in Python programming.

▶️ How to Run
python student_management.py
